# Вступ




Ласкаво просимо до <Edubeam />, вашого онлайн‑інструмента для статичного аналізу конструкцій. Тепер ви можете виконувати розрахунок конструкцій без інсталяції та складного налаштування.




<hr>




Перейдіть [за цим посиланням](https://run.edubeam.app/?lang=uk), щоб відкрити застосунок EduBeam і почати роботу.

## Можливості




- **Розрахунок 2D балок/ферм:** Легко моделюйте та аналізуйте плоскі конструкції.
- **Зручний інтерфейс:** Інтуїтивне керування для швидкої роботи.
- **Безкоштовно та онлайн:** Працює будь-де й будь-коли у браузері.
- **Орієнтовано на студентів і викладачів:** Функції, які підтримують навчальний процес.
- **Відкритий код:** Долучайтеся до розвитку EduBeam разом із спільнотою.
- **Простий обмін моделями:** Діліться своїми проєктами через URL.




## Автори




EduBeam — спільний проєкт, що розвивається завдяки внескам спільноти. Його підтримує невелика команда, пов’язана з кафедрою механіки [ČVUT Prague - Faculty of Civil Engineering](https://www.fsv.cvut.cz).










## Долучайтеся




Будемо раді вашим внескам у розвиток EduBeam:




1. **Код:** допоможіть з реалізацією нових можливостей у [GitHub‑репозиторії](https://github.com/rahulcvwebsitehosting/edubeam).
2. **Тестування:** повідомляйте про помилки та пропозиції через [issue tracker](https://github.com/rahulcvwebsitehosting/edubeam/issues).
3. **Документація:** покращуйте посібник та FAQ для нових користувачів.
4. **Поширення:** розкажіть про EduBeam колегам і студентам.




Дякуємо, що підтримуєте проєкт! 🚀
